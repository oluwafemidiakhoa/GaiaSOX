# Synthetic control registry and ledger

Five version 1.0.0 rules accept caller-supplied synthetic rows and expected IDs. Boolean fields are precomputed, not independently measured SQL facts. Unknown versions are rejected. The ledger is a single-writer JSONL hash chain, not immutable storage; retain its head independently to detect truncation or full rewriting. It does not authenticate evidence or prevent replay. Crash recovery and bounded ledger reads remain outstanding. The existing evidence CLI supports keygen, export and verify for the original single control; new controls are not yet integrated into that CLI. Private PEM keys are unencrypted. Run `python -m unittest discover -s tests -v`. Local observation: 15 tests passed with cryptography 46.0.4. No production or CI execution.
