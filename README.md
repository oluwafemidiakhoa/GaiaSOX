# GaiaSOX

Local-first SOX evidence engineering prototype. Synthetic data only. No production connections, deployment, or paid services authorized.

v0.1 scope: deterministic evidence evaluation, signed evidence envelopes, independent verification, and negative tests. A passing rule is not an audit opinion. Signatures prove integrity relative to an independently trusted key, not source completeness or truth.

Development changes belong on a review branch. Never commit credentials, private keys or employer evidence.
